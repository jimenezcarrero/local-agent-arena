Reading
  1. On this laptop, Vulkan is the backend for this model: prefill is 16-17x the CPU's for a cold 32K prompt and
     6-8x at 512 tokens; generation is 1.3-1.8x at an empty context and 5-6x at 32K depth. CPU numbers are for 4
     threads (the runbook's P-cores); T7's scoring used 8.
  2. Q4KM and M2 are close on Vulkan: Q4KM is faster with an empty context (pp512 449 vs 373, tg128 40.6 vs 35.5) and
     slower at 32K depth (pp512 83 vs 96, tg128 23.7 vs 26.5). Q4KM's 32K-depth prefill has the largest spread
     (+/-4.29). Not investigated further.
  3. REF does not run on the iGPU at all (heap budget), so a Q8_0 file of this model is CPU-only here.
  4. These are llama-bench numbers, not agentic turn times; whether either file is worth an arena run is the S1
     screen's question (fit at 32K/65K/131K first), not this measurement's.
